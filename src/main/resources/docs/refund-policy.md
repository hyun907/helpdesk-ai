# 유료 재화 환불 기준

## 1. 환불 가능 기간

- 결제일로부터 **7일 이내**이며, **해당 재화를 사용하지 않은 경우**에 한합니다.
- 일부라도 사용한 경우 잔여분에 대해서만 환불이 가능합니다.

## 2. 환불 금액 산정

- 환불 금액은 결제 금액에서 **이미 사용한 재화의 정가**를 차감한 금액입니다.
- 보너스로 지급된 재화는 환불 대상이 아니며, 사용분은 보너스 재화부터 차감한 것으로 계산합니다.
- 할인 이벤트로 구매한 경우 실제 결제 금액을 기준으로 환불합니다.

## 3. 환불 소요 기간

| 결제 수단 | 소요 기간 |
|---|---|
| 신용카드 | 승인 취소 후 3~5영업일 |
| 휴대폰 결제 | 당월 결제분은 즉시 취소, 익월 이월분은 계좌 환불 |
| 계좌이체 | 3영업일 이내 |
| 앱마켓 결제 | 해당 마켓 정책에 따름 |

**앱마켓(구글 플레이·앱스토어)을 통한 결제는 마켓에 직접 환불을 요청해야 합니다.** 회사가 직접 처리할 수 없습니다.

## 4. 환불이 제한되는 경우

- 제재 중인 계정의 환불 신청은 제재 기간 종료 후 처리됩니다.
- 환불 후 동일 계정에서 반복적으로 결제·환불을 되풀이하는 경우 결제가 제한될 수 있습니다.
- 이벤트로 무상 지급된 재화

## 5. 미성년자 결제

- 법정대리인의 동의 없이 이루어진 미성년자의 결제는 취소할 수 있습니다.
- 이 경우 가족관계 증명 서류가 필요하며, 접수 후 7영업일 이내에 처리됩니다.
