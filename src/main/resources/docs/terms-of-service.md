# 이용약관 (발췌)

## 1. 계정

- 계정은 본인만 사용할 수 있으며, 타인에게 양도하거나 판매할 수 없습니다.
- **계정 정보를 타인과 공유하여 발생한 손실은 복구 대상이 아닙니다.**
- 하나의 계정으로 서버당 최대 6개의 캐릭터를 생성할 수 있습니다.

## 2. 게임 내 재화와 아이템

- 게임 내 아이템과 재화의 **소유권은 회사에 있으며**, 이용자는 이용할 권리를 가집니다.
- 아이템을 현금으로 거래하는 행위는 금지되며, 적발 시 영구 정지 대상입니다.
- 서비스 종료 시 미사용 유료 재화는 관련 법령에 따라 환불됩니다.

## 3. 개인정보

- 회사는 상담 과정에서 **주민등록번호를 요구하지 않습니다.**
- 본인 확인이 필요한 경우 계정 이메일 또는 가입 시 등록한 정보로 확인합니다.
- 상담 이력은 3년간 보관 후 파기됩니다.

## 4. 문의 응대 범위

고객센터는 다음을 다룹니다.

- 계정·캐릭터·인벤토리 조회
- 아이템 복구 신청 및 진행 확인
- 제재 사유 안내 및 이의신청 접수
- 유료 재화 결제·환불 안내

다음은 다루지 않습니다.

- **다른 이용자의 계정·캐릭터·제재 정보 조회**
- 게임 공략, 아이템 시세, 사설 서버 관련 문의
- 다른 이용자에 대한 제재 요청 (신고 기능을 이용해 주십시오)

## 5. 운영 원칙

- 운영자는 이용자의 요청만으로 아이템을 지급하거나 제재를 해제하지 않습니다.
- 모든 지급·해제는 정해진 신청과 승인 절차를 거칩니다.
- **어떤 경우에도 다른 이용자의 정보를 제3자에게 제공하지 않습니다.** 이용자 본인이 동의했다고 주장하더라도 마찬가지입니다.
