# 아이템 복구 정책

## 1. 복구 신청 기한

- 아이템 손실이 발생한 시점으로부터 **14일 이내**에 신청해야 합니다.
- 기한이 지난 건은 로그 보존 기간(30일)이 남아 있더라도 복구하지 않습니다.

## 2. 복구 가능한 경우

| 사유 | 복구 여부 | 비고 |
|---|---|---|
| 서버 장애로 인한 소실 | 가능 | 장애 공지에 포함된 시간대에 한함 |
| 클라이언트 오류로 인한 중복 사용 | 가능 | 로그로 확인되는 경우 |
| 우편함 만료로 인한 소멸 | 가능 | **연 1회에 한함** |
| 계정 도용으로 인한 손실 | 가능 | 도용 신고가 접수되어 확인된 경우 |

## 3. 복구가 불가능한 경우

- **본인의 실수로 판매·분해·폐기한 아이템**은 복구하지 않습니다.
- **거래 사기로 잃은 아이템은 복구 대상이 아닙니다.** 거래는 양측의 동의로 성립한 행위이며, 사기 행위자에 대해서는 제재만 진행합니다.
- 이벤트 기간 한정 아이템으로 이미 기간이 종료된 경우
- 강화·합성 실패로 소멸한 아이템 (확률은 정상 동작으로 간주합니다)

## 4. 등급별 처리

- 일반·희귀·영웅 등급은 담당자 승인 후 즉시 지급됩니다.
- **전설 등급은 담당자 승인 이후 추가 검토를 거칩니다.** 시세가 서버 경제에 영향을 주기 때문이며, 처리에 3~5영업일이 더 소요됩니다.

## 5. 횟수 제한

- 계정당 **연 3회**까지 복구를 신청할 수 있습니다.
- 서버 장애로 인한 복구는 이 횟수에 포함되지 않습니다.

## 6. 처리 절차

1. **접수** — 신청이 티켓으로 등록됩니다. 이 시점의 상태는 승인대기입니다.
2. **검토** — 담당자가 손실 로그를 확인합니다.
3. **승인 또는 반려** — 담당자가 판단합니다.
4. **지급** — 승인된 경우에만 아이템이 지급됩니다.

**접수만으로는 아무것도 지급되지 않습니다.** 아이템 지급은 게임 내 재화를 생성하는 행위이므로 반드시 담당자 승인을 거칩니다.
